## What This Does

FitFindr is a thrift-shopping assistant that helps a user find clothing items based on a description, optional size, and maximum price. It searches available thrift listings and selects the best matching item. It then combines that item with pieces from the user's existing wardrobe to suggest outfits. Finally, it creates a short social-media-style fit card for the selected item and outfit.

---

## Tool Inventory

### `search_listings`

- **What it does:** Searches the available listings for items that match the user's description, optional size, and maximum price.
- **Inputs:** `description` (str), `size` (str or None), `max_price` (float or None)
- **Returns:** A list of matching listing dictionaries, ordered by keyword match score. Each dictionary contains fields including `id`, `title`, `description`, `category`, `style_tags`, `size`, `condition`, `price`, `colors`, `brand`, and `platform`.
- **When it has nothing:** Returns an empty list `[]` when no listings match the search.

### `suggest_outfit`

- **What it does:** Suggests one or two outfits by combining the selected thrift item with pieces from the user's wardrobe.
- **Inputs:** `new_item` (dict), `wardrobe` (dict containing an `items` list)
- **Returns:** A non-empty string containing outfit suggestions generated by the model.
- **When it has nothing:** If the wardrobe's `items` list is empty, it returns general styling advice for the new item instead of failing.

### `create_fit_card`

- **What it does:** Creates a short social-media-style caption for the selected thrift item and suggested outfit.
- **Inputs:** `outfit` (str), `new_item` (dict)
- **Returns:** A string containing a two-to-four sentence fit-card caption that mentions the item, price, platform, and outfit vibe.
- **When it has nothing:** If `outfit` is empty or whitespace, it returns a descriptive message explaining that a fit card could not be created.

---

## Planning Loop

**Branch rule:** If `search_listings` returns an empty list, the agent puts a helpful message in `session["error"]` and stops without calling `suggest_outfit` or `create_fit_card`. Otherwise, it selects the first matching listing and continues through the outfit and fit-card steps.

**Where it lives:** `agent.py::run_agent`

**How the query is parsed:** The query is parsed with regular expressions and string cleanup. The parser looks for a maximum-price phrase such as `under $30` and an explicit size such as `size M`. Those parts are removed from the remaining text, which becomes the item description passed to `search_listings`.

**What moves through the session:** The parsed query is stored in `session["parsed"]`, and the search results are stored in `session["search_results"]`. The first result is saved as `session["selected_item"]`. `suggest_outfit` reads the selected item and wardrobe from the session, and its result is stored in `session["outfit_suggestion"]`. `create_fit_card` then reads the outfit suggestion and selected item from the session, and the final caption is stored in `session["fit_card"]`.
